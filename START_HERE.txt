WHEEL STOCK — GITHUB START HERE

1. Upload this repository to GitHub.
2. Enable GitHub Pages using GitHub Actions:
   Settings → Pages → Build and deployment → Source → GitHub Actions.
3. Go to Actions and wait for "Build and publish wheel dashboard" to turn green.
4. Open Settings → Pages and click the live site link.

FUTURE:
Only add PDFs to the catalogues/ folder.
GitHub automatically processes them and rebuilds the dashboard.

Do not manually upload the site/ folder. It is generated by GitHub Actions.
